## ⚙️ How to Run

Follow these steps to run the Java programs on your local machine.

### Step 1: Clone the Repository

```bash
git clone https://github.com/Nagendra-2003/Java_BasictoAdvance_Program.git
```

### Step 2: Navigate to the Repository

```bash
cd Java_BasictoAdvance_Program
```

### Step 3: Open the Required Folder

For example, to access the array programs:

```bash
cd Array
```

You can also explore the `2D-Array`, `Input_and_Loop`, and `Pattern` folders.

### Step 4: Compile the Java Program

```bash
javac YourFile.java
```

### Step 5: Run the Program

```bash
java YourClassName
```

**Note:** Replace `YourFile.java` with the actual Java filename and `YourClassName` with the class name containing the `main()` method. Ensure that Java is installed and configured on your system.
